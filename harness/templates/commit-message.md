# 커밋 메시지

작성 전에 [협업 규칙](../quality/writing.md)을 읽고 staged diff를 확인한다. 제목은 필수이며 본문·이슈 연결은 필요할 때만 쓴다. 이 문서의 제목·안내·코드 울타리를 실제 커밋 메시지에 넣지 않는다.

```text
type(scope): 한국어 변경 내용

필요한 경우에만 변경 이유와 중요한 영향

Refs #번호
```

단순히 “수정”, “정리”라고 쓰지 않고 대상을 표현한다. 제목만으로 충분하면 본문을 채우지 않는다. 검증 결과를 적는다면 실제 실행한 내용만 쓴다.

```text
feat(commerce): 주문 재요청 시 기존 주문 반환
```

```text
fix(member): 만료된 갱신 토큰의 재사용 차단
```

```text
refactor(member): 로그인 테스트를 인증 패키지로 이동
```

```text
docs(common): 백엔드 팀 하네스 작성 기준 추가
```
