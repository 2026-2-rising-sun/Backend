# Backend 팀 하네스

AI가 팀의 코드·테스트·협업 기준에 맞춰 작업하도록 돕는 지침이다. 팀원이 결과를 검토할 때도 같은 기준을 사용한다. 문서는 한국어로 작성하며, 기존 도구와 테스트를 필요한 범위에서 활용한다.

## 적용과 개선

- `필수`는 지켜야 할 기준이다. `판단 기준`은 맥락에 따라 선택하되 예외가 결과에 영향을 주면 이유를 설명한다.
- 하네스는 팀의 기본값이다. 사용자가 정한 작업 범위와 예외를 반영하고, 일회성 예외를 팀 전체 규칙으로 바꾸지 않는다.
- 기존 코드 전체를 한 번에 고치지 않는다. 현재 변경 대상에 적용하고, 범위를 넘는 문제는 근거와 함께 남긴다.
- 같은 규칙은 한 문서에서 관리한다. 설정값은 실제 도구 설정이 원본이며, 설정이 바뀌면 안내도 함께 갱신한다.
- 반복적으로 해석이 엇갈리면 규칙과 예시를 개선한다. 변경 이유와 영향을 리뷰에 남기고, 아직 합의하지 않은 팀 정책은 `팀 논의 · 미확정`으로 표시한다.
- 하네스 문서를 위해 새 CI·검사기·장문의 작업 기록을 추가하지 않는다. 규칙이 지켜졌는지는 변경 내용과 검증 근거로 리뷰한다.
