Spec

이슈 목표 동작
#416 Payment가 UNKNOWN으로 답해도 처리 기한(600초) 전에는 PAYMENT_CONFIRMING을 유지한다. 기한 전 승인(조회·PaymentApproved)은 PAID, 기한 도달 때 보상 요청을 주문당 한 번 만든다
#417 COMPENSATION_PENDING으로 바꾸는 트랜잭션에서 재고·쿠폰 예약을 한 번 해제한다. 보상 결과는 다시 해제하지 않는다. 종료 상태는 CANCELLED
#418 승인 거절이 확정되면 PENDING_PAYMENT로 되돌리고 예약을 유지한다. 원래 만료 시각 전까지 새 결제창으로 재결제한다. 거절된 인증 결과는 재사용하지 못한다. 거절마다 PaymentFailed를 보내지 않는다. Payment CANCELED는 지금처럼 주문을 끝낸다. 202 뒤 거절도 포함한다
