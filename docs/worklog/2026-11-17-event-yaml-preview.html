목적과 현재 상태

사용자가 PR #361·#314의 내용을 확인하고 충돌을 해결한 뒤 병합하도록 요청했다. #361의 문서 구조 통합을 먼저 검증하고 dev에 병합했다(merge e79f2144). #314는 IntelliJ AsyncAPI 미리보기 호환을 위해 YAML 앵커·별칭을 명시적 정의로 펼치는 작업이다.

314 작성 이후 #329의 e5a1b66b가 별칭 제거와 서비스 명칭 호환을 이미 반영했다. 최신 dev의 이벤트 YAML 8개에는 앵커·별칭이 없다. 예전 #314의 스키마로 덮으면 새 생산자 source와 스키마 참조·예시가 역행할 수 있으므로, 충돌한 쿠폰·결제 묶음·방송 계약은 최신 dev 원문을 보존했다. 이번 최종 diff는 계약 변경이 아니라 확인·충돌 해결 기록이다.

원래 작업 폴더의 미커밋 문서·그림·계획은 보존하고 /tmp/backend-pr361-314-merge-20261117의 독립 Git 체크아웃에서만 작업했다. 새 Orca 에이전트나 워크스페이스는 실행하지 않았다.

  • 314의 원래 기준과 원래 head ff20da02의 계약 3개를 파싱한 결과가 동일함을 확인했다. 원래 변경은 별칭 확장이며 의미 변경이 아니다.
