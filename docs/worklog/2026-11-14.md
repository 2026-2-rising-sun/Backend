문서 하네스 기존 단위46개 통과, 문서127/API HTML6/설계 HTML28 정합성·공백 검사 통과. Orca browser의 실패 페이지인 공통 Core ERD에서 수정 전390px client390/scroll410을 재현했고 수정 후 client390/scroll390, select 경계 left14/right376/width362를 확인했다. SKU 필터 선택은1/17개 관계로 작동하며 페이지 폭을 유지했다.1280px는 client/scroll1265로 정상이다. 공통 도표는330px 영역/580px 내용의 내부 스크롤을 유지한다. Cart 독립 ERD도390px client/scroll390·도표356/내용1160으로 재확인했다. 공통 렌더러를 바꾼 뒤 Java 재검사를 반복하지 않으며 코드 검증 SHA `8397dca2`와 문서 후속 SHA를 구분한다.

SKU의 문서 전용 후속 `c0f3a52c`는 `bfe54902`로 일반 merge했다. 공통 ERD 충돌은 최신 SKU 검증 설명과 Cart 통합 상태를 함께 유지한 뒤 원본에서 재생성했다. `git diff 8397dca2 -- services/commercecore-service/src services/catalog-service/src contracts`가 비어 코드·SQL·계약이 같은 것을 확인했다. 최종 문서 기록 추가 뒤 링크·생성물 검사를 갱신하며, 새 CI 결과는 PR HEAD에서 별도로 확인한다.
