구현 기준: 2026-11-13 git fetch origin 후 로컬 HEAD와 origin/dev는 모두 e5a1b66bf3b06a971b1242dd02bd623e717c2902였고 양방향 차이는 0이었다. 기존 이슈·전용 브랜치·워크트리와 미커밋 이관 변경을 이어서 작업했다. 커밋·푸시·PR은 수행하지 않았다.

관련 자료: 구조와 주석 · 시각 구조도 · 판단 기준 · 현황 조사 · 모듈별 문서 범위 · 일일 작업 기록

목표와 범위

AI 에이전트가 요청 범위를 지키고 팀의 공통 기준으로 조사·변경·검증·기록하도록 기존 하네스를 재구성한다. 다음 사람이 작업의 목적과 결정 이유, 실제 실행 결과를 찾아 이어받을 수 있게 한다.

  • 루트 harness/의 문서·검사기를 docs/와 scripts/로 이관하고 진입점과 실행 경로를 연결한다.
  • 참고 이미지처럼 docs/ 바로 아래에 명세·요구사항·ADR·설계·실행 계획·워크로그를 둔다.
  • 복잡한 작업은 exec-plans/active/<이슈번호>-<주제>/README.md에서 계획·상태·관련 자료를 연결한다. 필요한 판단·조사 자료를 같은 폴더에 추가한다.
  • MD는 AI 에이전트가 참조하기 쉬우면서 사람도 읽을 수 있는 원본으로, HTML은 사람이 구조·흐름·차이를 이해하는 시각 자료로 관리한다.
  • 6개 서비스의 모듈별 API 명세·DB ERD·실제 상태 전이를 MD·HTML로 문서화한다. API 명세의 원본은 기존 OpenAPI YAML이며 HTML은 이를 표시하는 파생 자료다.
  • 공통 모듈은 공통 처리와 Outbox를 설명하고, 여러 서비스가 협력하는 흐름은 상위 설계 문서로 연결한다.
  • 기존 코드·테스트·Git 협업·API/이벤트 계약 기준과 검증기의 실패·스킵·0건·미실행·검사 중 변경 구분을 보존한다.

서비스 업무 동작과 API·이벤트 계약은 이번 개편의 변경 대상이 아니다. 가드·편집 후 훅·MCP 설정은 실제 사용 목적과 연결 경로가 정해질 때 별도로 구현한다. 커밋·푸시·PR·병합·배포는 사용자가 허용한 범위에서 수행한다.

자동 검사와 수동 검토의 상세 결과는 워크로그에 있다. 생성기의 제한된 Markdown 지원·코드와 설계 의미의 수동 대조는 기술부채에 남겼다.

기록 작성 조건

자료 작성할 때 배치와 갱신
공통 ADR 구조·기술·책임 경계처럼 여러 작업에 지속적으로 영향을 주는 결정을 내릴 때 docs/adr/에 결정·대안·이유·영향·상태를 남긴다. 작업 문서는 해당 ADR을 링크한다.
실행 계획 여러 단계·의존성·불확실성이 있거나 다른 사람이 이어받을 작업일 때 작업 폴더의 README.md에 목표·범위·순서·진행 상태·검증·관련 링크를 둔다.
작업별 판단·조사 해당 작업의 선택 근거나 조사 결과를 분리해 보존할 내용이 있을 때 decision.md, research.md 등을 추가한다. 공통 ADR과 내용을 중복 관리하지 않는다.
워크로그 실제 변경이나 의미 있는 조사·검증을 수행하고 작업을 마무리하거나 인계할 때 docs/worklog/YYYY-MM-DD.md에 이슈별로 결과·근거·미확인 사항을 추가한다.
프롬프트·표·HTML 재현할 입력이나 분리할 분석 자료, 시각 설명이 필요할 때 관련 작업·설계 문서 옆에 필요한 파일만 작성한다.

단순 질의응답에는 별도 기록을 만들지 않는다. 작은 수정은 일일 기록의 관련 작업 항목에 요약한다. 명령과 대화 전체보다 다음 작업의 판단과 재현에 필요한 내용을 남긴다.

4. 모듈별 문서의 원본과 생성·갱신 방식을 정한다

  • [x] 모듈별 문서 범위에 따라 각 서비스의 계약, 마이그레이션, 엔티티, 상태 변경 코드와 관련 테스트를 조사한다.
  • [x] 모듈 문서의 공통 구성을 README.md, api.html, erd.md, erd.html, states/<주제>.md와 같은 이름의 HTML로 정한다.
  • [x] API HTML은 서비스 YAML과 공통 참조를 입력으로 생성한다. OpenAPI 렌더러·버전을 정하고 scripts/render-api-docs.sh에서 생성과 최신성 확인 방법을 제공한다. 명세를 MD에 다시 복사하지 않는다.
