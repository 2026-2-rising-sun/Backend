## 범위

기준 `dev` / `2ef0a6c8`. 기존 미커밋 지침·고도화 초안·워크로그를 보존하고 문서 이동과 생성·검사 경로만 수정한다. 서비스 업무 코드와 API·이벤트 계약 의미는 변경하지 않는다.

## 완료 조건

- [x] 서비스 간 흐름과 서비스·모듈별 ERD·API 경로가 통합된다.
- [x] 기존 진행 계획·수용 기준·검증 근거와 사용자 미커밋 내용이 보존된다.
- [x] 주제별 MD·HTML 쌍과 링크·생성 최신성 검사, 관련 회귀가 통과한다.
- [x] 대표 흐름·ERD·API의 데스크톱·좁은 화면과 탐색을 확인한다.
- [x] 작업 지침·템플릿·로컬 검사·CI를 새 구조에 맞춘다.

## 결과와 후속

로컬 문서·계약 정적·도구 회귀 검사와 대표 브라우저 검토를 마쳤다. 실행 결과는 워크로그에 기록했다. 서비스 기능의 기존 미완료 사항은 각 계획에서 계속 추적하며 이번 구조 변경으로 완료 처리하지 않는다.
