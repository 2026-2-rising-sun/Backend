# CommerceCore 코드 가독성과 재고 처리 순서 정리

상태: 진행 중. [이슈 #362](https://github.com/2026-2-rising-sun/Backend/issues/362).

## 범위

Cart 응답의 깊은 중첩과 Order 주문서 생성 흐름을 정리한다. 기존 결제 결과가 주문 항목 ID가 아닌 SKU ID 순서로 재고를 변경하게 하고 빈 반복문·오래된 이름·미사용 의존성을 제거한다. 트랜잭션과 잠금 순서, 멱등성, 기한, 쿠폰 및 이벤트 원자성을 유지한다. Payment 구현과 보류된 환불·다중 SKU 정책은 바꾸지 않는다.

- [x] 실제 재고 변경의 SKU 정렬을 보장하고 빈 반복문을 제거한다.
- [x] 변경 전 성공·실패 결과의 역순 처리 회귀 2건이 실패하는 것을 확인한다.

- [ ] PR 제목·본문·최종 HEAD CI와 미해결 리뷰를 확인하고 dev에 병합한다.
