# 실행 계획

여러 단계·의존성·불확실성이 있는 작업은 `active/<이슈>-<주제>/README.md`에서 목표·범위·진행 상태·검증·관련 자료를 연결한다. 내용이 필요한 판단·조사 자료만 같은 폴더에 추가한다.

진행 작업: [#333 Product](active/333-product-module/README.md) · [#334 SKU](active/334-sku-module/README.md) · [#332 Cart](active/332-cart-module/README.md). 각 모듈 독립 구현과 공유 통합 검증을 구분한다.

완료 작업: [#331 Order 기존 범위](completed/331-order-module/README.md) · [#330 문서 하네스](completed/330-document-harness/README.md)

완료 기준을 확인한 뒤 작업 폴더를 `completed/`로 옮기고 링크를 갱신한다. 남은 과제는 [기술부채](tech-debt.md)와 후속 이슈로 연결한다. 진행 중인 필수 작업을 완료 처리하지 않는다.

Order 별도 후속 [#345 동시 환불](https://github.com/2026-2-rising-sun/Backend/issues/345)·[#346 결제 준비/실행 기한 분리](https://github.com/2026-2-rising-sun/Backend/issues/346)는 사용자 요청으로 나중에 전용 작업 공간에서 진행한다. 기존 범위 완료는 정책 전체 승인·운영 검증을 뜻하지 않는다.
