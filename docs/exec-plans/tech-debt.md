# 기술부채

| 항목 | 현재 한계·영향 | 다시 다룰 조건 |
|---|---|---|
| ERD·상태 설명의 의미 검토 | 링크·생성 최신성은 검사할 수 있지만 코드의 모든 전이를 자동 증명하지 않는다. 코드 변경 시 관련 문서와 테스트를 대조한다. | 변경량이 늘어 수동 대조 누락이 반복될 때 추출 범위와 비용을 평가한다. |
| Markdown 검사 지원 범위 | 기본 링크·ATX 제목 중심이며 모든 CommonMark 확장·CSS URL·동적 JS 이동을 해석하지 않는다. | 실제 사용하는 문서 문법을 잘못 판정할 때 회귀 예시와 함께 확장한다. |

가드·MCP는 필요가 확정되지 않아 기술부채로 간주하지 않는다. 실제 문제·영향·재검토 조건이 생길 때 항목을 추가한다.
