# 부분 수량 환불과 쿠폰 정책 조사

출처: 코디네이터가 제공한 공식 정책 조사 기록을 보존했다. Order 담당은 이 기록을 독립 재조사 결과로 표현하지 않는다.

확인일: 2026-11-13. 범위: 쿠팡·올리브영·무신사의 공개 공식 자료. 실구매·고객센터 문의·운영 코드 확인은 하지 않았다.

## 사용자 확정과 조사 결론

우리 구현은 4,000원×3개에 쿠폰2,000원을 적용해 10,000원 결제한 뒤 순차 환불액을 4,000/4,000/2,000원으로 정하고 전량 환불 성공 시 쿠폰을 복구한다. 이전 비례배분 제안을 대체한다. 기존 쿠폰 원래 유효기간은 유지한다.

세 서비스에서 이 순차 금액 알고리즘과 누적 전량 복구를 함께 사용한다고 확인할 수 없었다. 아래 공개 정책의 범위만 확인했으며 동일 SKU 수량별 원 단위 배분이나 내부 계산식은 추측하지 않는다. 조사 결과는 이미 승인된 구현을 막거나 변경하지 않는다.

## 공식 근거와 접근 한계

1. [쿠팡 행사 쿠폰 안내](https://m.coupang.com/vm/promotions/1792126/event): 본문 행사기간 2025-09-10~2026-12-31, 상품금액 비율 분할 적용·부분 환불 및 전체/부분 재발행 조건. 공식 본문 직접 열기 확인. 특정 행사 적용 규칙이다.
2. [올리브영 FAQ — 취소/교환/반품](https://www.oliveyoung.co.kr/store/counsel/getFaqList.do?faqLrclCd=200&faqMdclCd=204): 「환불 금액이 이상해요」 및 「쿠폰이 복구되지 않았어요」 본문 직접 열기 확인. 수량별 할인 배분·순차 환불 예시는 없다.
3. [무신사 FAQ — 혜택](https://store.musinsa.com/app/cs/faq/005/005000): 검색 결과에 쿠폰 사용·반환 및 적립금 환불 예시 본문이 노출된다. 직접 열면 신규 FAQ로 이동하며 웹 도구에는 빈 목록만 노출되어 현재 전체 본문 직접 확인은 제한되었다. 검색 색인은 오래될 가능성이 있어 계산 정책의 확정 근거로 사용하지 않는다.
4. [무신사 앤디얼 첫 구매 쿠폰](https://www.musinsa.com/onboarding/engagement/andearfirst): 현재 공개 본문에서 상품 단위 적용과 환불 후 쿠폰 유효기간 내 재사용을 직접 확인했다. 특정 쿠폰 조건이며 전체 쿠폰 공통 계산 규칙 증거는 아니다.

## 우리 구현의 의미와 검증

두 개 환불 후 남은 한 개의 실제 부담액은 2,000원이다. 쿠폰 할인2,000원이 남은 상품에 유지되는 효과다. 주문 당시 최소 구매액을 환불 때 다시 심사하는 정책은 이번 사용자 지시에 없으므로 새로 도입하지 않는다.

순차 1+1+1과 일괄 2+1, 동시 환불의 금액/수량 잠금, 실패와 재시도, 중복 성공, 할인액이 커서 잔여 환불액0인 수량, 전량 성공 시 쿠폰 단일 복구·기존 만료 유지, 다른 항목이 남았을 때 미복구를 Order 담당이 검증한다. 이 문서는 조사/구현 지시 기록이며 해당 코드/테스트 완료 보고가 아니다.
