# Phase 1 설계 리뷰 기록

리뷰: 2026-11-15, 독립 리뷰 에이전트 1회(읽기 전용). 대상: 이 폴더의 설계서 4장, `phase1-payment.md`, 결제·원장 요구사항, `decision.md`, ADR 0337-1~5, `design.html`, 현재 payment-service 코드.

## 높음 — 돈 정합성

| # | 문제 | 고친 내용 | 위치 |
|---|---|---|---|
| 1 | 1차 승인 결과 불명 → 2차 재호출이 연결 실패면 CREATED로 되돌림. 1차가 이미 승인됐다면 재결제가 가능해진다 | 한 번이라도 불명을 받은 시도는 CREATED로 되돌리지 않고 UNKNOWN으로 두어 조회로 확정 | [338 §2 ③](338-approval-ledger.md#2-승인-처리) |
| 2 | 승인 반영 UPDATE가 0행이면 그냥 끝냄. 조회기가 먼저 CREATED로 돌린 뒤 DONE이 오면 돈만 빠지고 기록이 없음 | 0행이면 다시 읽음. APPROVED면 끝, 그 밖이면 ERROR 로그 + 보상 취소 | 338 §2 ③ |
| 3 | 보상 취소 대상 paymentKey가 DB 값인지 응답 값인지 불명. 트랜잭션 경계 없음 | 취소 대상은 **토스 응답의 paymentKey**. pg_call 먼저 기록 → 트랜잭션 밖 호출 → CANCELED | 338 §2 보상 취소 |
