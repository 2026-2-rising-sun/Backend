범위와 불변조건

고정 enum이 아니라 토큰 used_at·family 시각·회원 상태로 설명한 수명 주기다. 없는 토큰으로 임의 family를 폐기하지 않는다. 일반 로그아웃·refresh 만료만으로 기존 접근 JWT 유효 기간을 줄이지 않는 실제 구현에 유의한다.

전이

1 refresh_families와 해시 토큰을 생성하고 JWT에 세션 ID를 넣는다.

2 회원·family 잠금 후 used_at을 기록하고 같은 family에 다음 토큰을 발급한다.

3 실제 저장 토큰 재사용이면 family의 revoked_at·security_revoked_at을 기록한 뒤 401을 응답한다.

4 로그아웃은 revoked_at만 기록한다. 이미 발급된 접근 JWT를 즉시 만료시키지 않는다.

5 expires_at 경과로 refresh를 거절한다. 접근 JWT의 만료는 별도로 검사한다.

6 비밀번호 확인 후 withdrawn_at과 모든 family의 보안 폐기를 같은 트랜잭션에 기록한다.

7 security_revoked_at 또는 withdrawn_at이 있거나 세션 소유권이 맞지 않으면 활성 확인에 실패한다.
