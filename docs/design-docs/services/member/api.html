Member Service API

회원가입·로그인·프로필·세션 관리 API. JSON 성공·오류 응답은 ApiResponse 봉투이며 204는 본문이 없다. Access 수명은 15분, refresh family는 최초 로그인부터 절대 30일이며 rotation으로 연장되지 않는다. 일반 로그아웃은 refresh만 폐기하여 기존 access의 남은 수명을 허용한다. refresh 재사용·판매자 본인 세션 폐기·탈퇴는 이후 신규 인증 검사부터 access도 차단한다. 이미 인증 검사를 통과한 요청을 소급 취소하지 않는다. 쿠키를 사용하지 않는다.
