범위와 불변조건

상태 enum 대신 read_at과 행 존재로 표현한다. 타인 소유와 존재하지 않는 ID는 모두 404다. 알림 삭제는 원본 주문·결제·환불 기록을 지우지 않는다. 서비스 주석의 과거 이벤트 미구현 표현보다 실제 이벤트 소비·저장 코드를 함께 읽는다.

전이

1 이벤트 ID와 회원 ID의 유일 조건으로 알림을 저장한다. 중복 이벤트가 같은 알림을 늘리지 않게 한다.

2 본인 알림만 read_at IS NULL 조건으로 갱신한다. 목록 조회만으로 읽음 처리하지 않는다.

3 재요청과 전체 읽음 처리에서 최초 read_at을 보존한다.

4 created_at이 보관 기준보다 오래되면 읽음 여부와 별도로 제한된 수량을 삭제한다.

5 기본 P30D 보관 기준·회당 최대 10000개를 사용한다. 삭제 실패는 로그 후 다음 주기에 재시도한다.
