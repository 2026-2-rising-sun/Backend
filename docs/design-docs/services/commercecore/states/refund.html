범위와 불변조건

commercecore.refunds.execution-enabled가 꺼져 있으면 REFUND 전달을 하지 않는다. 공개 API 사용 가능 여부와 실행 토글은 계약·설정을 따로 확인한다. 중복 결과와 누적 환불 금액을 확인하며 일부 환불만으로 결제 묶음 전체를 환불 완료로 만들지 않는다.

전이

1 성공한 원결제·소유자·기간·대상·누적 금액·멱등 원문을 검사하고 refund_request와 대상을 영속화한다.

2 Payment의 유효한 미확정 응답을 전달 기록과 환불 요청에 반영한다.

3 Payment의 현재 미확정 스냅샷에 따라 다시 PROCESSING을 기록할 수 있다.

4 원문·금액·대상 검증 후 주문 PAID→REFUNDED, 재고 복원을 같은 트랜잭션에서 처리한다.

5 조회·이벤트로 확정된 성공 결과를 같은 결과 처리 경로로 반영한다.

6 확정 실패를 기록하며 성공 환불의 재고 복원을 수행하지 않는다.

7 실행 결과가 실패로 확정된 경우에만 변경한다.
