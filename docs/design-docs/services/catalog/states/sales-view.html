범위와 불변조건

이는 Core 판매 상태를 변경하는 상태 기계가 아니라 사본 갱신과 화면 표시 규칙이다. 원본 재고를 Catalog가 예약하지 않는다. replica/HTTP 조회 설정과 구매 시점 원본 검증을 구분한다.

전이

1 backfill은 없는 행만 삽입하며 이미 수신한 이벤트를 덮지 않는다.

2 판매 이벤트의 snapshotVersion으로 최초 사본을 삽입한다.

3 M>N인 이벤트만 반영한다. 동일·역순 버전은 갱신하지 않는다.

4 READY·ON_SALE·SOLD_OUT·PRIVATE를 그대로 매핑한다. 공개 노출은 ON_SALE/SOLD_OUT, 구매 가능 표시는 ON_SALE이다.

5 정상 조회에서 판매정보가 없는 경우.

6 외부 조회 실패를 품절이나 미등록으로 치환하지 않는다.
