Payment Service 내부 API

브라우저 공개 경로가 없는 독립 결제 실행 서비스. Core가 주문·환불 정책과 공개 facade를 소유한다. 전용 Payment DB의 결제/환불 실행과 결과 Outbox만 소유한다. 결제 ID는 Core 영속 전달 ID이며 Payment PK로 그대로 사용한다. 서비스 사이 FK는 없다. 재시도 예산 소진 뒤에도 UNKNOWN 결과 조회는 계속한다.
