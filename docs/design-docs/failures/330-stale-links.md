# #330 문서 이관 중 루트 링크 단절

상태: 원인 확인 · 최종 검증은 [작업 기록](../../worklog/2026-11-13.md) 참고

기존 harness 문서를 docs/guides로 옮긴 뒤 AGENTS가 옛 경로를 가리켜 문서 검사에서 19개 오류가 발생했다. 파일 이동과 진입점 갱신이 분리된 중간 상태가 원인이다.

AGENTS·문서 지도·명령을 새 경로로 갱신한다. 이후 이동 작업은 참조 검색과 전체 문서 검사를 함께 수행한다. 삭제된 구현을 가리키는 링크도 찾기 위해 CI의 문서 검사는 코드만 변경해도 실행한다. 과거 오류 기록은 현재 미해결 오류와 구분한다.
