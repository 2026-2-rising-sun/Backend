# ShoppingLive 제품 범위

상태: 현재 구현 설명

판매자는 상품·판매·방송·프로모션을 운영하고, 사용자는 방송 시청 중 채팅·좋아요로 참여하며 상품을 조회해 장바구니·쿠폰·주문·결제를 이용한다. 알림함과 방송·재입고 구독으로 변화를 확인한다.

- 회원과 세션: 가입·로그인·갱신·로그아웃·탈퇴.
- 구매: 공개 상품 탐색, 판매·재고 확인, 쿠폰과 주문 묶음, 결제·환불 처리.
- 판매와 방송: 상품 원본·이미지·판매 상태, 방송 등록·시작·종료, 상품 연결·프로모션.
- 실시간 참여와 알림: SSE·채팅·좋아요, 이벤트 기반 알림함과 구독.

결제 제공자는 현재 Mock이다. IVS 로컬 stub과 외부 어댑터를 구분한다. 실제 PG·외부 송출 운영 완료를 제품 기능 설명만으로 주장하지 않는다.

책임과 상세 정책은 [아키텍처](../../ARCHITECTURE.md), [모듈 문서](../design-docs/services/README.md), [계약](../../contracts/api)을 따른다. 정책을 변경할 때 해당 요구사항·설계·계약과 함께 갱신한다.
