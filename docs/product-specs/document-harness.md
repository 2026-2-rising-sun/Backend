# 문서 하네스 제품 명세

상태: 채택 · 구현과 검증은 [요구사항](../requirements/document-harness.md)에서 추적

사용자는 Backend 팀원과 AI 에이전트다. 요청 범위를 지키면서 같은 구현 맥락으로 작업하고, 다른 사람이 선택 이유와 검증 결과를 찾아 이어받을 수 있어야 한다.

- 시작 시 행동 기준·서비스 경계·관련 문서를 찾는다.
- 작업 중 결정·조사·계획을 필요한 크기로 남긴다.
- API·ERD·상태를 사람이 HTML로 탐색하고 에이전트는 계약·MD·코드를 참조한다.
- 마무리 시 실제 검증 결과와 미확인 범위를 기록한다.

이번 범위는 기존 지침 이관, 기록 절차, 6개 모듈과 공통 모듈의 문서, 로컬·CI 검사다. 업무 코드·API/이벤트 계약 변경, 배포, 형식적인 훅·MCP 설치는 포함하지 않는다.
