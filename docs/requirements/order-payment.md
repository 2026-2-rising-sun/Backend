## 원래 설계 수용 기준

- [ ] 주문서 공개 생성부터1:N스냅샷·SKU선점·PENDING600초를 지원한다. 현재는내부도메인만검증하고공개입구는미제공이다.
- [ ] 실제실행진입부터PAYMENT_PROCESSING별도600초를지원하며준비/재전송으로시작·연장하지않는다. legacy 실행 접수의 별도 타이머는 구현했다. 새 Payment 준비/승인 중계는 미완이다.
- [ ] UNKNOWN의기한초과종료·조회·늦은승인보상계약을정의하고구현한다. 주문 기한에는 EXPIRED와 선점해제를 적용한다. PG실패로 확정하지 않으며 새 Payment 조회/환불 이벤트 연동은 미완이다.
- [ ] 모든신규경로에최신기한요구를적용하고기존저장기한을보존한다. 새 공개legacy의기본600초와별도처리600초는적용했다. 기존확인중null기한/새Payment중계는미완이다.
- [ ] 실제수량환불·누적전량쿠폰복원·중복/롤백·늦은승인보상을완료한다. 독립계산도메인만남기며금전어댑터는미연결이다.

독립결함수정·테스트통과를전체설계완료로바꾸지않는다. Payment담당코드/계약을대신수정하지않으며PR은Draft·머지불가다. 기존실행은 [보존기록](../exec-plans/completed/331-order-module/verification.md), 현재검증은2026-11-15보완계획/워크로그에서구분한다.
