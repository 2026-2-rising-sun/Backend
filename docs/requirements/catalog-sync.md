# Catalog 동기화 수용 기준

상태: 초안
검증: [현재 설계와 테스트 근거](../design-docs/catalog-sync.md)

## 수용 기준

- [ ] 중복·낮은 snapshotVersion은 최신 사본을 덮지 않는다.
- [ ] backfill은 없는 판매 사본만 version 0으로 채운다.
- [ ] 조회 실패를 품절로 표시하거나 사본을 원본 재고 확정으로 취급하지 않는다.

현재 구현에서 확인할 조건을 정리했다. 이번 문서 작업에서 실제 DB·Kafka 테스트를 재실행하지 않았으므로 완료로 표시하지 않는다.
